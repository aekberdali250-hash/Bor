Bor Reward App — النسخة المحسّنة متعددة اللغات
================================================

محتويات الحزمة:
- index.html: الصفحة الرئيسية المحسّنة، واللغات مضمّنة داخلها.
- server.js: خادم Express وواجهات API وقاعدة البيانات الحالية.
- admin.html: لوحة الإدارة.
- admin-login.html: صفحة دخول الإدارة.
- package.json: اعتماديات Node.js وأمر التشغيل.
- README.txt: تفاصيل النشر والاختبار.
- .env.example: أسماء متغيرات البيئة كمثال فقط، لا يحتوي أسرارًا حقيقية.
- .gitignore: يمنع إضافة الملفات المؤقتة والأسرار إلى Git.

هذه حزمة موقع ويب Node.js، وليست ملف APK ولا مشروع Android.
لا تحتاج الصفحة الرئيسية إلى مجلد CSS أو JS منفصل؛ تنسيقها وكود الترجمة داخل index.html.

للمحافظة على الموقع الحالي:
1) لا تحذف قاعدة بيانات PostgreSQL الحالية ولا تنشئ قاعدة جديدة.
2) في مستودع GitHub الحالي aekberdali250-hash/Bor والفرع Bormain، استبدل الملفات المتطابقة فقط عند الحاجة.
3) إن أردت نشر التصميم فقط، استبدل index.html وحده؛ لا تستبدل server.js أو إعدادات Render بلا داعٍ.
4) إذا أردت تحديث المشروع كاملًا، راجع الملفات قبل رفعها، ثم ارفع الملفات إلى جذر المستودع وليس ملف ZIP نفسه.
5) في Render احتفظ بقيم DATABASE_URL وADMIN_PASSWORD وSESSION_SECRET الحالية. لا تنشر أي سر في GitHub.
6) أمر البناء المعتاد: npm install
   أمر التشغيل: npm start
7) بعد النشر اختبر /api/health، التسجيل، تغيير اللغات، صفحة /admin/login، ثم تحميل العروض.

مهم:
- الواجهة متعددة اللغات لا تعني أن عروض AdGem متاحة في كل بلد.
- لا تعلن عن السحب النقدي أو المكافآت الحقيقية حتى يتم اختبار تكامل AdGem والتحويل التجريبي بنجاح.
- تسجيل المستخدم الحالي نموذج أولي ويستخدم معرّفًا محليًا في المتصفح؛ ليس بديلًا عن نظام حسابات آمن كامل.
